# Добавление темы

Тема — отдельный `.md`-файл внутри папки главы. В нём краткое описание, инсайты и ссылки на материалы.

## Что спросить (если не указано)

- Книга и глава
- Название темы, порядковый номер внутри главы
- Краткое описание, инсайты (списком)
- Ссылки: видео YouTube, видео VK, презентация, доп. материалы (title + url)
- Спикер(ы) и их мнение (если есть)

## Шаги

1. Найди папку главы: `books/<slug>/chapters/<NN-глава>/`.
2. Создай файл темы `<MM-slug-темы>.md` (`MM` — порядок внутри главы):
   ```markdown
   ---
   id: <book-id>-<номер главы>-<номер темы>
   title: …
   order: 1
   video_youtube: ""
   video_vk: ""
   presentation: ""
   resources:
     - title: …
       url: …
   speakers:
     - Имя Фамилия
   ---

   ## Краткое описание

   …

   ## Инсайты

   - …

   ## Мнение спикера

   **Имя:** …
   ```
   Пустые поля оставляй как `""` / `[]`. Секцию «Мнение спикера» опусти, если мнений нет.
3. Добавь тему в `topics` внутри `chapter.json` главы:
   ```json
   { "id": "<тот же id>", "title": "…", "file": "<MM-slug-темы>.md" }
   ```
4. Проверь `JSON.parse` для `chapter.json` и `npx prettier --check` по новым/изменённым файлам.
5. Коммит: `feat(books): добавить тему "<Название>" в главу <NN>`. Не пушить.

## Соглашения

- `id` темы уникален в рамках книги, формат `<book-id>-<глава>-<тема>` (напр. `docker-intro-1-2`).
- Спикеров для аватарок заводи скиллом `add-speaker`.
