# Добавление карточек

Карточки книги хранятся в одном файле `books/<slug>/flashcards.json` (общая колода, пополняется по мере глав).

## Что спросить (если не указано)

- Книга и глава (номер)
- Карточки (можно списком). Для каждой — тип:
  - `qa`: вопрос + ответ
  - `command`: команда + результат
- Сложность каждой карточки: `easy` / `medium` / `hard`

## Шаги

1. Открой (или создай пустой массив) `books/<slug>/flashcards.json`.
2. Определи префикс id по книге (напр. `docker`) и следующий свободный номер, продолжая автоинкремент.
3. Добавь карточки:
   ```json
   { "id": "docker-006", "type": "qa", "question": "…", "answer": "…", "chapter": "2", "difficulty": "easy" }
   { "id": "docker-007", "type": "command", "command": "docker …", "result": "…", "chapter": "2", "difficulty": "medium" }
   ```
   `id` — формат `<префикс>-NNN` (трёхзначный, с ведущими нулями).
4. Проверь `JSON.parse` и **уникальность всех `id`** в файле (частая ошибка).
5. `npx prettier --check` по файлу.
6. Коммит: `feat(books): добавить карточки к главе <N> "<Книга>"`. Не пушить.

## Соглашения

- Один `flashcards.json` на книгу (без разбивки по файлам-главам).
- `chapter` — строка с номером главы.
