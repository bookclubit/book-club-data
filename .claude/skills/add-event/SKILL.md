# Добавление встречи

Два типа встреч. Спроси тип, затем заполни соответствующую схему.

## Что спросить (если не указано)

- Тип: `closed-chapter` (закрытая, разбор главы) или `live-talk` (открытая, доклады)
- Дата (`YYYY-MM-DD`), время, таймзона (по умолчанию `Europe/Moscow`), тема
- Для закрытой: книга, глава, страницы для чтения, ссылка на доску заметок
- Для открытой: ссылки на стримы (YouTube, VK), список докладов (тема + спикер), ссылка на регистрацию

## Шаги

1. Проверь формат даты — строго `YYYY-MM-DD`.
2. Имя файла: `events/<тип>/<YYYY-MM-DD>-<тема-slug>.json` (папки: `events/closed-chapters/`, `events/live-talks/`).
3. Закрытая встреча:
   ```json
   {
     "id": "closed-<дата>-<slug>",
     "type": "closed-chapter",
     "title": "…",
     "date": "2026-07-20",
     "time": "19:00",
     "timezone": "Europe/Moscow",
     "book_id": "<book-id>",
     "chapter": "<NN-глава>",
     "pages": { "from": 1, "to": 24 },
     "notes_board_url": "https://…"
   }
   ```
4. Открытая встреча:
   ```json
   {
     "id": "live-<дата>-<slug>",
     "type": "live-talk",
     "title": "…",
     "date": "2026-07-25",
     "time": "19:00",
     "timezone": "Europe/Moscow",
     "streams": { "youtube": "https://…", "vk": "https://…" },
     "call_url": "https://meet.google.com/…",
     "talks": [
       {
         "title": "…",
         "speaker": "Имя Фамилия",
         "speaker_id": "<speaker-id>",
         "avatar": "/media/speakers/<speaker-id>.webp"
       }
     ],
     "program": [
       { "book_id": "<book-id>", "chapter": "<NN-глава>", "topic_ids": ["<id-темы>"] }
     ],
     "recordings": { "<id-темы>": { "youtube": "https://…", "vk": "https://…" } }
   }
   ```
   - `program` — программа эфира блоками: **несколько глав и даже книг за вечер**.
     Порядок блоков = порядок вечера. `topic_ids` внутри блока — темы именно этой
     встречи: нужно, когда главу делят на несколько эфиров («Часть 1» / «Часть 2»).
     Пусто/нет поля = вся глава.
   - Старые встречи вместо `program` хранят `book_id` + `chapter` + `topic_ids`
     прямо в событии — это тот же единственный блок. В новых встречах так
     не писать.
   - `call_url` — созвон встречи (Google Meet): бот выдаёт ссылку записавшимся,
     в приложении появляется кнопка «Подключиться». Бывает и у эфира с докладами.
   - `recordings` — монтажные ролики докладов (id темы → ссылки). Показываются на
     странице спикера вместо записи всей встречи; заполняются после монтажа.
5. Спикеров и их аватарки заводи скиллом `add-speaker` (нужен корректный `speaker_id` и файл аватарки).
6. Проверь `JSON.parse`, что аватарки спикеров резолвятся, `npx prettier --check`.
7. Коммит: `feat(events): добавить встречу <дата> "<Тема>"`. Не пушить.
