# Добавление главы

Создаёт главу как папку-контейнер для тем. Сами темы добавляются скиллом `add-topic`.

## Что спросить (если не указано)

- Книга (slug или название)
- Порядковый номер и название главы
- Описание главы и `learning_outcome` (чему научит)

## Шаги

1. Определи книгу: `books/<slug>/`.
2. Создай папку `books/<slug>/chapters/<NN-slug-главы>/`, где `NN` — двузначный порядковый номер (`01`, `02`…), slug главы — kebab-case (транслит рус. названия).
3. Создай `chapter.json` — это **индекс** главы (тексты живут в файлах-темах):
   ```json
   {
     "order": 1,
     "title": "…",
     "description": "…",
     "learning_outcome": "…",
     "topics": []
   }
   ```
   `topics` — массив ссылок на файлы-темы, заполняется скиллом `add-topic`.
4. При необходимости обнови `total_chapters` в `books/<slug>/meta.json`.
5. Проверь `JSON.parse` и `npx prettier --check` по новым файлам.
6. Коммит: `feat(books): добавить главу <NN> "<Название>"`. Не пушить.

## Связанные скиллы

Наполнить главу: `add-topic`. Карточки к главе: `add-flashcards`.
