# Добавление новой главы

Создай новую главу книги. Выполни шаги:

1. Спроси название книги (если не указано)
2. Спроси номер и название главы
3. Спроси описание главы (чему научит)
4. Создай папку `books/{книга}/chapters/{номер}-{название}/`
5. Создай `chapter.json` с полями: title, order, description, learning_outcome, subchapters (пустой массив)
6. Проверь JSON на валидность
