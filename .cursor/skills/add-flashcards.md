# Создание карточек для запоминания

Добавь новые карточки в банк книги. Выполни шаги:

1. Спроси книгу и главу
2. Спроси вопросы и ответы (можно списком)
3. Добавь записи в `flashcards.json` книги
4. Каждая карточка: id (автоинкремент), type (qa/command), question, answer, chapter, difficulty
5. Проверь уникальность id
